## First sentence to use when sharing the repository

> Loan Approval Project started as a college loan-approval ML project and evolved into a business-analysis system that helps a lending team decide what to automate, what humans should review, how to prioritize work, whether staffing can handle demand, and where the process is breaking.

## Recommended GitHub reading order

1. `README.md` — project/problem/value in plain English
2. `docs/PROJECT_OVERVIEW.md` — concrete 1,000-application walkthrough
3. `docs/BUSINESS_ANALYSIS_FRAMEWORK.md` — BA/BizOps framework and KPIs
4. `docs/RESUME_AND_INTERVIEW.md` — defensible interview story
5. `docs/MODEL_CARD.md` — technical and responsible-use boundary
